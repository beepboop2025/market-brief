01 / On your website

One small context desk.

Paste the iframe into a page that allows embedded HTML. Your reader clicks Build to request data. Loading the widget alone makes no market-data requests.

The widget is responsive; adjust the iframe height to suit your page. Its evidence list scrolls. A topic changes what is shown; every Build still reads the same three sources.

Hosting and privacy details

Your site must permit frames from https://beepboop2025.github.io. The widget needs JavaScript and access to https://api.seiche.info. Its links open in a new tab.

The embed sets no local storage and sends no analytics or parent messages. Hosting and source providers receive ordinary web requests. There are no automatic refreshes; manual checks are limited to once a minute. Loading a new page starts a new check with no comparison baseline.

No custom source URLs or tracking parameters are supported. This public hosted widget can evolve independently of the pinned v0.1.0 skill. Free early access does not promise permanent free hosting or uninterrupted upstream availability.

02 / In your newsletter

A link readers can use.

Email clients generally block scripts and iframes. Use this short introduction and link to the browser brief instead. The same link works in a community post.

If you add an excerpt, keep the observation date, source link and relevant gaps beside it. A screenshot or copied value becomes a dated snapshot; it does not refresh inside an email.

Evergreen copy, with no invented current values. Review the final email in your publisher’s editor.

03 / In an existing workflow

Let the context travel.

Install the v0.1.0 Agent Skill in a compatible assistant, or run its Python helper locally. It reads the same selected sources and can compare a saved brief on your next manual check.

The standalone helper needs Python 3.10 or newer and no external AI model. Your assistant provider’s subscription may cost separately.

Release instructions and comparison examples ↗

Keep the evidence intact

Build with the context.

The skill and Python helper are the reusable integration today. There is no additional hosted Market Brief API or MCP server to register.

  • Keep observation time, source generation time and retrieval time separate. Carry the original source links and distinguish observed data from derived context.
  • Retain partial, missing and withheld states. A successful request does not establish fresh observations or complete coverage; do not turn gaps into zeroes.
  • The code is MIT-licensed. Upstream data keeps its own rights and restrictions; public access is not blanket permission to republish it. Review those terms before publishing excerpts or native data.
  • Respect source publication cadence. Repeated calls do not create new evidence. No ticker catalysts, earnings calendar, holdings advice or order execution are supplied.
